# 성산 자율주행 — 최종 PPO 모델 (final-ppo-model)

제주 성산 일대 도로(SUMO, +1차로 v4 지도)를 한 바퀴 주행하는 PPO 자율주행 모델과, 이 모델을 **실행·평가하는 데 필요한 파일만** 모은 브랜치입니다.
학습 코드와 실험 기록은 `seongsan-ppo-w9-20261124` 브랜치에 있습니다.

## 파일 구성

| 경로 | 내용 |
|---|---|
| `models/final_ppo/model.pt` | 최종 PPO 체크포인트 (actor/critic MLP 256×256, 입력 63, 행동 9) |
| `models/final_ppo/observation_names.json` | 입력 63개의 이름과 순서 |
| `models/final_ppo/training_config.json` | 학습 설정 (보상, 작업 구성, 작업별 교통량) |
| `maps/seongsan/generated_pluslane_v4_20261124/` | SUMO 지도 (net / rou / add / gui / sumocfg) |
| `paper_training/`, `utils/`, `train_observed_driving.py` | 주행 환경(관측·행동·종료 판정)과 정책 불러오기 |
| `view_policy_gui.py` | sumo-gui로 주행 보기 |
| `evaluate.py` | 화면 없이 반복 평가 (충돌률·완주율) |

## 설치

Python 3.11, SUMO 1.27.1 기준입니다.

```bash
pip install -r requirements.txt     # libsumo==1.27.1, eclipse-sumo==1.27.1 포함
```

## 실행

```bash
# GUI로 주행 보기 (교통량 1.5배, 4배속; 창을 닫을 때까지 에피소드 반복)
python view_policy_gui.py --traffic 1.5 --speed 4 --seed 920000

# 화면 없이 평가 (예: 교통량 1배, 1000회)
python evaluate.py --traffic 1 --episodes 1000 --seed 920000 --workers 8
```

`evaluate.py`는 결과 요약을 출력하고, 에피소드별 결과를 `results/eval_<교통량>x.jsonl`에 저장합니다.

## 성능 (1000 에피소드, seed 920000–920999)

| 교통량 | 충돌률 | 완주율 | 신호 위반 | STOP 위반 | 경로 이탈 | 평균 속도 | 한 바퀴 |
|---|---|---|---|---|---|---|---|
| 1배 | **2.1%** (±0.9) | 97.7% | 0 | 0 | 0.2% | 33.4 km/h | 117 s |
| 1.5배 | **4.6%** (±1.3) | 94.3% | 0.2% | 0.1% | 0.8% | 33.6 km/h | 114 s |
| 2배 | 7.7% (±1.6) | 91.7% | 0.1% | 0.3% | 0.2% | 31.5 km/h | 120 s |

- 괄호는 95% 신뢰구간입니다.
- 교통량 배수는 지도 기본 교통 흐름(`seongsan.rou.xml`의 vehsPerHour)에 곱한 값입니다.
- 한 에피소드는 고정 출발점에서 전체 경로를 한 바퀴 도는 것입니다. 다음 중 하나가 일어나면 끝납니다.
  - 충돌
  - 적색 신호 위반
  - STOP 표지 앞에서 완전히 멈추지 않고 통과
  - 경로 이탈
  - 도착
  - 시간 초과
- 2배 교통 충돌의 대부분은 south_t 교차로(양보 좌회전)와 south_cross에서 납니다.

## 모델 구성

**행동: 9개 이산 행동** (0.2 s마다 선택)
- `index = 3 × 종방향 + 횡방향`
- 종방향: 감속(−4 m/s²) / 유지 / 가속(+3 m/s²)
- 횡방향: 오른쪽 차선 / 유지 / 왼쪽 차선
- SUMO의 자동 안전 기능은 모두 꺼져 있습니다(`speedMode=96`, `laneChangeMode=0`). 모든 가감속과 차로 변경은 정책이 결정합니다.

**관측: 63개 입력**
- 자차 속도·가속도
- 앞·뒤·옆 차로 차량의 거리와 속도
- 교차로 주변 격자 점유
- 신호 색(적·황 여부)과 거리
- STOP·양보 표지
- 교차로에서 경로가 겹치는 차량의 거리·속도·도착 시간
- 경로 정보(현재 차로로 계속 갈 수 있는 거리, 필요한 차로 방향, 다음 분기까지 거리)
- 일부 항목의 0.8 s 전 값

**보상** (설정 값은 `training_config.json`)
- 실패(충돌, 신호·STOP 위반, 경로 이탈) −10
- 도착 +10, 교차로 통과 +5
- 속도 보상: 목표 속도에 가까울수록 큼. 목표 속도는 앞차·신호·STOP·교차로 상황에서 IDM으로 계산합니다.
- 정지 상태에서 출발해야 할 때 −1
- 차로 변경 −4, 위험한 차로 변경 −6

**학습**
- PPO입니다.
- 이전 모델에서 이어서 학습했고, 이 체크포인트는 마지막 단계의 약 200만 스텝 지점입니다.
- 학습 작업은 8개 워커가 나눠 맡습니다.
  - 전체 경로 3개 (교통량 3·5·2배)
  - 교차로 3개
  - STOP 1개 (1배)
  - 신호 1개

## 사용한 규칙
- 주행 중에는 규칙 기반 보조나 시나리오 전환 없이 정책 하나만 행동을 결정합니다.
- 경로 정보는 큰 틀의 라우팅(차로 끝까지 거리, 분기 방향)만 줍니다.
