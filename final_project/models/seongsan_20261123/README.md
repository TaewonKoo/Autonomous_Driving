## 실제 보상

| 항목 | 추가되는 값 | 조건 |
|---|---|---|
| 시간 | `-0.001*5*0.2 = -0.001` | 매 스텝 |
| 충돌 | `-10` | 충돌 시, 종료 |
| 적신호 위반 | `-0.25-0.02*v` | 충돌이 없는 적신호 통과 시, 종료; v는m/s |
| 완주 또는 교차로 통과 | `+1` | 실패 없는 스텝, OR조건으로 한번 지급 |
| 필수정지 하위목표 | `+1` | 요청·실제속도0(수치허용1e-6), 정지선5m내 첫 이행, 노드당 한번 |
| 과속 | `-0.002*max(0,v-v_limit)` | 전체경로 비실패 스텝 |
| 정지위반·경로실패·시간초과 | 별도 추가벌점0 | 종료 및 기본 시간비용은 존재 |

충돌/적신호/정상 성공 항은 `if/elif`로 배타적입니다. 정지 하위목표와 과속은 각각 별도 조건으로 적용됩니다.
전체 보상 클리핑과 실패 후 시간비용 보정은 적용하지 않았습니다.

성공+1·충돌-10은 Isele, 시간·과속·신호 계수는 Zhu에서 참고했습니다.
**교차로마다+1을 반복 지급하는 것, 필수정지 하위목표+1, 시간 항에만dt=.2를 곱하는 것, 종료 조건과 보상 결합은 성산 구현 설계**입니다.
Zhu 원문 Eq24에는dt곱이 명시돼 있지 않고, 원문 전체보상[-1,1] 클리핑·연료·배터리·jerk·missed-green 항은 그대로 적용하지 않았습니다.

## 학습·입출력·제어

- 정책망 `200→64(tanh)→64(tanh)→9 logits`, 별도 가치망 `200→64(tanh)→64(tanh)→1`.
- PPO `gamma=.99`, `GAE=.95`, 전체2048전이/업데이트, 요청512×4. 학습은Categorical표본추출, 평가는argmax.
- 별도Adam, beta(.9,.999), epsilon1e-8. 기존 프레임워크 기본값이며 검증된 논문 지정값으로 주장하지 않습니다.
- Advantage정규화(표준편차하한1e-6), 가치MSE, 엔트로피 보너스0, gradient/value clipping없음.
- 입력은SUMO/TraCI 수치 상태입니다. 이미지 인식은 사용하지 않습니다.
- 행동은가감속(-4,0,+3m/s²)×차로방향(-1,0,+1)의9개입니다. 차로방향은 인접차로 이동이며 교차로 좌우회전 명령이 아닙니다.
- 경로는미리 지정된`ego_loop`입니다. 정책은 전역 경로를 새로 탐색하지 않습니다.
- 실제dt=.2초, 제한시간500초, 속도상한50km/h, 차량길이5m, 교통배수1.
- speedMode96/laneChangeMode0. 별도 종방향 안전필터는 없지만 SUMO의 이동 계산·차로 요청 처리에 따른 요청/실제속도 차이는 남습니다.
- 차로변경3초는TraCI 요청 유지시간이며 실제 횡이동이3초라는 뜻이 아닙니다.
- 훈련에서는배경교통을 재사용하고 평가는매회 시드를 지정해 재초기화합니다.

## 기록 해석

원본 config의 `effective_profile.dt=.1`, `steps=1000000`, `seeds=[23]` 등은 이번 실행에 쓰이지 않은 기본 메타데이터입니다.
실제 환경dt=.2, 모델별 시드24/25, 최종스텝3502080을 확인하세요. `runtime.steps=3500320`은 요청 목표이고2048단위 갱신으로 실제3502080이 됐습니다.
원본 config의 일부 과거 출처 문구(시간 항의per-second 해석 등)는 보존했습니다. 실제 계산과 `reward_source_verification.json`의 교정 내용을 우선 확인하세요.
실행기록의 로컬 프로젝트 경로는 `<PROJECT>`로 치환했고 수치값은 보존했습니다. 원본 파일해시는 `recorded_runs/RECORD_METADATA.json`에 있습니다.
Adam 상태와 후보 출발 가중치 파일은 추가 배포하지 않았습니다. 시작 가중치 해시·계승 관계는 기록돼 있습니다.
